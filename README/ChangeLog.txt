	- Algorithmic changes for lineage:
		- Previously used graph based methods for finding connections between sequences, this could result in clumps of distinctly different sequences being connected by a few sequences between them.
		- Switched to a more agglomerative clustering based approach which helps prevent this as well as increases memory efficiency and decreases computation time.  
2014.01.02
	- Samples were previously clustered individually resulting in lineages being connected to multiple different lineages across cell populations.  To eliminate this occurance, samples are now clusted together in one step. For the most part there is no large change on output in terms of clonal distributions, connections between populations though can be altered anywhere from slightly (common) to drastically (rare).  With this most of the output files have changed.
