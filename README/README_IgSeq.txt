NAME
     IgSeq

SYNOPSIS
     perl IgSeq
     perl IgSeq merge lineage compare

DESCRIPTION
     This script executes the IgSeq scripts: merge.pl; lineage.pl; comparelineage.pl
     This script and all others must be extracted/installed into the /Applications/IgSeq directory.

SETTINGS
     Three options are available to run sub-scripts separately.  Generally used for testing purposes only.
        - merge:  will run only the merge script
        - lineage: will run only the lineage script
        - compare: will run only the comparelineage script

OUTPUT
     Consists of the individual output from each program.  See README documents for each in terms of their
     respective output files.

CAVEATS
     This program must be extracted into the Applications folder in the root directory.  Running these scripts on
     a non-Unix based platform has not been tested.
